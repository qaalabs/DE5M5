## Create GitHub Repository

- Make sure everyone is signed in to github.com in the browser first - first GitHub touchpoint of the day
- Use template → create repo → explore structure (all in browser, no clone yet)
- Branch protection: make sure they uncheck "Require approvals" - the default is on and solo learners cannot merge their own PRs
- If anyone accidentally edits on main, GitHub creates a branch and PR - expected behaviour, just close the PR and delete the branch
- Add Mermaid diagram to docs/architecture/index.md - check it renders before moving on
- Create docs/decisions/ADR-001.md - paste ADR from Notepad
- They now have two artefacts committed - diagram and ADR
