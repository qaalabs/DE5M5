## Local Development Setup

- Open Terminal
- Git config first (email, name) - same two lines as M4
- Clone their repo: `git clone https://github.com/USERNAME/qa-library-pipeline.git`
- First clone/push on a fresh VM triggers a GitHub sign-in popup (Git Credential Manager) - walk them through it here so it doesn't derail the push later this afternoon
- `git remote -v` after cloning - confirms origin is set before they start editing
- Navigate in, explore the structure locally
- Note: learners with resetting VMs need to clone again each morning
