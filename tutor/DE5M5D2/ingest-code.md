## Ingestion Activity

- Full activity: `day2/ingestion-code.md` - three checkpoints: `load_csv()`, `load_json()`, then a stretch (`load_text()` for the feedback file)
- Learners post "1 done" / "2 done" in the chat at each checkpoint and carry straight on - they do not wait for you to check
- Read the gaps, not the flags: about 10 minutes in, go to anyone who has not posted "1 done"
- Only stop the class if several are stuck on the same thing - the `pd.json_normalize()` REPL check is the one worth doing live
- Every checkpoint ends with a commit and push, so GitHub or `umfundi` shows who has really changed each function
- The tests in `test_ingestion.py` are still empty stubs - the checkpoint commands are the real check, testing is taught this afternoon
