## Ingestion Activity

- Full activity: `day2/ingestion-code.md` - three checkpoints: `load_csv()`, `load_json()`, then a stretch (`load_text()` for the feedback file)
- Checks run in Jupyter Notebook - learners create `notebooks/sandbox.ipynb` at checkpoint 1 and reuse it all day; help anyone who cannot get Jupyter started
- Learners post "1 done" / "2 done" in the chat at each checkpoint and carry straight on - they do not wait for you to check
- Read the gaps, not the flags: about 10 minutes in, go to anyone who has not posted "1 done"
- Only stop the class if several are stuck on the same thing; the `pd.json_normalize()` notebook check is the one worth doing live
- Every checkpoint ends with a commit and push, so GitHub or `umfundi` shows who has really changed each function - the notebook cells are the real check, `test_ingestion.py` is still empty stubs until this afternoon
