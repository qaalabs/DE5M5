## Validation Activity

- Learners implement `validate_isbn()` in `validation.py` - currently returns its input unchanged
- Core rules provided: 13 digits, strip hyphens, all digits
- Check digit calculation is a stretch goal - most learners at confidence 2-3 will stop at length and digit checks
- Learners check it in the `sandbox` notebook - known valid and invalid ISBNs with expected results are on the page
- Solution to post in chat when the activity ends: [validation-solution](https://qaalabs.github.io/DE5M5/day2/validation-solution/) (`day2/validation-solution.md`)
