# Kanban

A simple visual system for managing work in progress.

| To Do | In Progress | Testing | Done |
|-------|-------------|---------|------|
| Tasks waiting | What you're working on now | Needs checking | Complete |

- One card per task
- Move cards as work progresses
- Limit what's "In Progress" - finish before starting something new
