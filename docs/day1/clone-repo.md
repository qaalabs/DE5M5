# Clone your Repository

Open **Terminal** from the Desktop.

## Step 1: Git config

```sh
git config --global user.email "you@example.com"
git config --global user.name "Your Name"
```

## Step 2: Clone your repo

```sh
git clone https://github.com/YOUR_USERNAME/qa-library-pipeline.git
cd qa-library-pipeline
```

Replace `YOUR_USERNAME` with your GitHub username.

## Step 3: Switch to the dev branch

```sh
git checkout dev
```

## Step 4: Explore the structure

```sh
dir
```

You should see the same folders you explored on GitHub earlier.
