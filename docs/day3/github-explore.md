# Activity: Explore Your GitHub Repo

Your dev branch is merged. Take 20 minutes to explore what GitHub is showing you about your project.

## Actions tab

Click **Actions** in your repo. You will see every CI run from today.

- Click into a completed run - explore the steps
- Expand the test step - your full pytest output is here
- Find the coverage summary in the logs - what percentage did you actually hit?
- Look at a failed run if you have one - read the error

## Pull requests

Click **Pull requests** -> **Closed**. Your merged PR is there.

- Open it - you can see the full timeline: every commit, every CI run, the merge
- Click **Files changed** - this is a diff of everything you wrote over two days

## Commits

Click **commits** on the main branch. This is the full history of your project.

- How many commits did you make?
- Can you see the story of the project in the commit messages?

## Insights

Click **Insights** -> **Contributors**. You can see your commit activity across the project.

Try **Network** under Insights - this shows the branch history visually, including the dev branch and the merge point.

## Anything else?

Have a look around. GitHub surfaces a lot of information about a project - most developers only use a fraction of it.
